# Venture Launch OS

Venture Launch OS is a reusable operating system for taking a business from **idea → validation → brand → website → backend → SEO/AEO → AI visibility → GTM → outreach → operations → growth** with minimal repeated instruction.

## Use it

Give an LLM or coding agent this raw skill file:

`https://raw.githubusercontent.com/Emodv/venture-launch-os/main/SKILL.md`

Then prompt:

> Launch this business using Venture Launch OS: [describe the business idea, target customer, geography, and any existing assets].

The system should infer what it can, research what it must, build what tools permit, and surface only genuine blockers.

## Core principles

- Revenue before elegance
- Validate before scaling
- Mobile-first conversion
- Backend and analytics from day one
- SEO + local SEO + AI-agent discoverability
- Reusable automation and structured data
- Tight unit economics
- Maximum three active priorities

## Repository structure

- `SKILL.md` — master operating instructions
- `BRIEF_TEMPLATE.md` — minimal intake format
- `playbooks/` — execution playbooks
- `templates/` — reusable technical and marketing templates
- `examples/` — reference implementations and case studies

## Reference implementation

DK / Dry Kleaning was the first business used to develop this operating model: a mobile-first local-service platform with quoting, backend lead capture, local/service SEO pages, schema, `llms.txt`, OpenAPI/MCP discovery, off-page SEO, outreach, and operational validation.
