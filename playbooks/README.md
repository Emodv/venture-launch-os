# Playbooks

Reusable execution playbooks for Venture Launch OS and Venture Launch Agent (VLA).

## Available

- `ZERO_TO_ONE_DISCOVERY.md` — idea, problem, ICP, validation and fatal-constraint discovery.
- `NAME_DOMAIN.md` — naming, domain research, brandability and conflict checks.
- `TECHNICAL_LAUNCH.md` — repo, stack, Vercel, DNS, SSL and production launch.
- `DESIGN_SYSTEM.md` — Quiet Luxury / Quiet Power, mobile-first UX and progressive conversion.
- `CONTENT_AUTHORITY_ENGINE.md` — original expertise, Q&A, comparisons, case studies and authority content.
- `BUSINESS_INFRASTRUCTURE.md` — business, tax, policy, payments and operating requirements classification.
- `SEO_AEO_AI_VISIBILITY.md` — technical SEO, content authority, generative-search citation readiness, agent technology and measurement.
- `AI_NATIVE_WEBSITE_OPTIMIZATION.md` — master process for upgrading any site from legacy web → search ready → AI discoverable → agent ready → AI-native using SEO, AEO, structured discovery, API/CLI/MCP and WebMCP.
- `AI_AGENT_READINESS_WEBMCP.md` — XML/search discovery, semantic machine-readability, WebMCP browser-native tools, agent-operable journeys and verification.
- `ANALYTICS_ATTRIBUTION_QA.md` — funnel analytics, attribution, production QA and data-quality checks.
- `PPC.md` — paid acquisition validation, CAC controls, measurement hierarchy and scaling rules.
- `OUTREACH.md` — prospect/partner prioritization, sequences, tracking and outcome attribution.
- `OPERATIONS.md` — lean fulfillment, system of record, exception handling, automation and fixed-cost gates.

## Operating standard

Every playbook should define objective, inputs, execution rules, KPIs, verification, risks, kill criteria, and automation opportunities.

For websites, the default modernization path is:

`SEO foundation → entity clarity → AEO/content authority → machine discovery → API/CLI/MCP → WebMCP → measurement`

New and existing sites should be assessed for human usability, search visibility, machine readability and safe machine operability.
