# Templates

Reusable assets for launching new ventures quickly.

Planned templates:
- mobile-first landing page
- city/service SEO page
- Supabase lead schema
- CRM pipeline
- llms.txt
- services.json
- agent manifest
- OpenAPI specification
- MCP documentation/server skeleton
- analytics event map
- outreach tracker

Templates should be factual, configurable, and safe to reuse across different businesses without carrying over private client data.
