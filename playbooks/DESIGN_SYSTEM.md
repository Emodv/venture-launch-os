# Venture Launch OS Design System

## Objective
Create a clean, mobile-first interface with Quiet Luxury / Quiet Power: premium, restrained, confident, minimal, and conversion-focused.

## Default visual character
The site should feel:

- calm
- premium
- deliberate
- confident
- uncluttered
- high-trust
- contemporary without chasing trends

Avoid:

- template-like startup aesthetics
- excessive gradients
- oversized decorative blobs
- too many cards
- icon overload
- stock-photo overload
- fake social proof
- dense menus
- long walls of copy
- aggressive sales language
- decorative animation that slows interaction

## Mobile-first law
Design the mobile experience first. Desktop is an adaptation.

Primary QA widths:

- 375px
- 390px
- 430px
- 768px
- 1440px

Assume mobile is the primary traffic surface unless data proves otherwise.

## Layout
Default rules:

- centralized content when visually appropriate
- narrow readable text measure
- generous whitespace
- strong section rhythm
- one dominant CTA per screen/section
- minimal navigation
- thumb-friendly controls
- no accidental horizontal overflow
- large enough type and tap targets

## Typography and copy
Language should express Quiet Power:

- short sentences
- concrete benefits
- few superlatives
- no inflated AI/startup jargon
- no begging for attention
- no unsupported leadership claims

Prefer:

> Qualified customers. When you need them.

Over:

> Revolutionary AI-powered next-generation growth solutions that transform your business.

## Progressive conversion
Do not expose a long form unless the task genuinely requires it.

Prefer:

`choice → personalization → useful result/estimate → contact details → confirmation`

Use:

- option cards
- segmented selectors
- calculators
- step-by-step questions
- drawers/modals
- progressive disclosure

Collect higher-friction information only after the visitor receives context or value.

## Carousel rule
Use horizontal swipe/scroll-snap carousels on mobile when multiple comparable choices would otherwise create excessive vertical clutter.

Good uses:

- services
- industries
- case studies
- portfolio
- testimonials when verified
- products/options

Do not hide critical information in a carousel when simultaneous comparison is important.

## Above the fold
The first screen should usually communicate:

- what this is
- who it is for
- primary outcome/value
- one CTA
- optional trust/proof element when factual

## Interaction rules

- visible focus states
- clear selected states
- clear loading/success/error states
- avoid unexpected layout shifts
- avoid autoplay sound/video
- minimize typing on mobile

## Performance
Design decisions must protect speed:

- optimize images
- avoid unnecessary JS
- lazy-load non-critical media
- use system/efficient fonts where practical
- avoid heavy animation frameworks unless justified

## Final design QA
Before launch inspect every primary page and flow on mobile first for:

- alignment
- text wrapping
- CTA visibility
- touch targets
- form usability
- carousel behavior
- overflow
- contrast
- speed
- hierarchy

A site is not approved merely because desktop looks good.
