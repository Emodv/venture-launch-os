# Playbooks

Reusable execution playbooks for Venture Launch OS.

## Available

- `SEO_AEO_AI_VISIBILITY.md` — technical SEO, entity clarity, structured data, AI discovery, citation assets and off-page authority.
- `PPC.md` — paid acquisition validation, CAC controls, measurement hierarchy and scaling rules.
- `OUTREACH.md` — prospect/partner prioritization, sequences, tracking and outcome attribution.
- `OPERATIONS.md` — lean fulfillment, system of record, exception handling, automation and fixed-cost gates.

## Next modules

- analytics and attribution
- CRM and lifecycle automation
- local/off-page SEO deep dive
- provider/fulfillment partner sourcing
- launch QA / production verification

Each playbook should define objective, inputs, execution rules, KPIs, kill criteria, risks, and automation opportunities.
