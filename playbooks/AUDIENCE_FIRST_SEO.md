# Audience-First SEO

## Source principle
This playbook is based on the Audience-First SEO framework described by Nikki Lam / NP Digital in the material provided by the user.

The core shift is:

> Do not start SEO with keyword volume. Start with the audience segments that create the most business value, then size search demand and opportunity inside those segments.

The framework in the source has three moves:

1. Define the audience.
2. Size the market by segment.
3. Run the gap analysis against the audience.

It also extends the same audience map into digital PR.

---

# Why this matters to VLA

Traditional SEO can optimize for traffic that does not become qualified pipeline or revenue.

VLA must optimize for economic ownership, not raw search volume.

A segment with enormous search demand can be less valuable than a much smaller segment if the smaller audience has higher customer value, stronger purchase intent, better fit, or better conversion potential.

Therefore VLA must not rank SEO opportunities by search volume alone.

---

# Move 1 — Define the audience before the keywords

Before keyword research, define the commercially meaningful audience segments.

For each segment capture where known:

- segment name
- ICP/persona
- industry / category
- company size or consumer profile
- geography
- problem / job-to-be-done
- buying trigger
- purchase intent
- likely product/service fit
- average customer value / ACV / LTV where known
- expected conversion quality
- strategic importance
- exclusions / low-fit audiences

For an existing business, use first-party evidence where available:

- CRM customer data
- GA4 conversions
- Search Console landing/query data
- paid search conversion data
- sales pipeline/won deals
- customer interviews
- revenue by product/service/segment

Do not infer profitability or customer value from traffic alone.

---

# Move 2 — Size demand by audience segment

Build a search-demand map for each defined audience rather than one undifferentiated keyword universe.

Measure where data is available:

- total relevant search demand
- commercial-intent demand
- informational/problem-aware demand
- current rankings
- ranking difficulty / competitive strength
- current organic traffic
- current organic conversions
- content coverage
- SERP / answer-engine competition
- AI citation opportunity where measurable

Then score the segment using three dimensions from the source framework:

1. Search demand
2. Ranking difficulty / attainability
3. Business value

VLA should add conversion/economic evidence when available without changing the source framework's core ordering.

## Default opportunity model

Use a normalized scoring model rather than raw volume:

`Audience SEO Opportunity = Business Value × Demand × Attainability`

When reliable conversion data exists, VLA may refine with:

`Economic SEO Opportunity = Business Value × Demand × Attainability × Conversion Evidence`

Do not let a high-volume, low-value audience outrank a smaller, high-value audience solely because of volume.

---

# Move 3 — Run the gap analysis against the audience

Traditional gap analysis often asks:

> Which keywords do competitors rank for that we do not?

Audience-First gap analysis instead asks:

> What information, pages, answers, comparisons, proof, and experiences does our highest-value audience need that we do not adequately own?

For each priority segment compare:

- current site coverage
- competitor coverage
- current rankings
- search intent coverage
- funnel-stage coverage
- answer-engine / LLM retrieval coverage where observable
- authority/proof gaps
- conversion-path gaps

Possible actions:

- improve an existing ranking page
- create a dedicated service/product landing page
- create supporting problem/solution pages
- create comparison/alternative pages
- create decision/pricing guides
- create original research/data/calculators
- strengthen proof/case studies
- add internal links from existing authority pages
- consolidate overlapping low-value content
- remove or deprioritize traffic-heavy content that attracts the wrong audience

# Existing Business Transformation workflow

For VLA Mode B, Audience-First SEO must happen after the public audit and first-party-data request, before a large content migration or SEO roadmap is finalized.

Sequence:

`URL → public audit → first-party access → Preservation Map → Audience Map → segment demand sizing → audience gap analysis → content/SEO roadmap → migration/upgrade`

Use GA4 and Search Console when authorized to answer:

- Which audiences are already arriving?
- Which landing pages attract qualified users?
- Which queries produce traffic but poor business outcomes?
- Which smaller topics produce disproportionately strong conversion?
- Which high-value segments are underserved?
- Which URLs must be preserved because they contribute meaningful qualified traffic or conversion?

Do not delete high-traffic content automatically. Classify it by audience/business value first.

---

# Greenfield workflow

For VLA Mode A, do not open a keyword tool first.

Sequence:

`ICP → audience segments → business-value ranking → segment search demand → attainable opportunity → content architecture`

If no first-party data exists, label business-value assumptions explicitly and update them as leads/customers arrive.

---

# Audience-First AEO / AI visibility

Apply the same audience map beyond Google blue links.

For each high-value segment determine:

- questions they ask in search
- questions they ask LLMs/answer engines
- comparison prompts
- objections
- decision criteria
- trusted sources/entities they reference
- data/evidence needed to make a decision

Then produce pages/assets that are easy for both humans and AI systems to retrieve and cite accurately.

Do not create generic AEO pages for every possible prompt. Prioritize prompts belonging to commercially meaningful audiences.

---

# Audience Map → Digital PR

The source framework also uses the audience map to multiply digital PR.

VLA should use high-value audience segments to guide:

- original research topics
- data studies
- surveys
- commentary angles
- journalist/outlet targeting
- industry publications
- partner campaigns
- expert POV

The objective is not generic backlinks. It is authority and distribution in the information environments that influence the target audience.

A PR placement is more valuable when it reaches, influences, or is cited for the priority audience.

---

# Reporting

For every SEO/AEO plan, report at minimum:

## Priority audience segments
Ranked by business value, demand, and attainability.

## Audience Opportunity Matrix
For each segment:
- Business Value: /10
- Search Demand: /10
- Attainability: /10
- Conversion Evidence: /10 or UNKNOWN
- Priority: HIGH / MEDIUM / LOW

## What we intentionally will NOT chase
List high-volume segments/keywords that are low-fit or low-value.

## Audience gaps
The pages, answers, proof, tools, and authority assets missing for priority audiences.

## Top 3 moves
Highest-value SEO/AEO actions based on audience economics rather than traffic volume.

---

# Rule

VLA does not optimize for the largest audience.

VLA optimizes for the most valuable audience it can realistically win, then compounds search, AEO, content, PR, and agent visibility around that audience.
