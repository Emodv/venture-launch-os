# Templates

Reusable assets for launching new ventures quickly.

## Available

- `AI_DISCOVERY_TEMPLATE.md` — llms, services, agent manifest, OpenAPI/MCP guidance and agent truth boundaries.
- `AI_AGENT_READINESS_CHECKLIST.md` — 100-point audit for search discovery, schema/entity clarity, machine-readable assets, WebMCP tools, permissions and production verification.
- `UNIT_ECONOMICS_TEMPLATE.md` — contribution margin, CAC ceiling, payback and LTV scenario framework.
- `STARTER_APP_SPEC.md` — reusable technical foundation for new ventures.
- `PRODUCTION_LAUNCH_CHECKLIST.md` — production verification before calling a venture live.
- `VENTURE_STATE_SCHEMA.md` — persistent conceptual state model for VLA ventures.

Templates must be factual, configurable, and safe to reuse across ventures without carrying over private client data, unsupported claims, prices, locations, or credentials.
