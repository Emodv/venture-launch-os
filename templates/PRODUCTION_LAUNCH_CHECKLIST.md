# Production Launch Checklist

Use this as the final gate before calling a venture launched.

## Strategy
- [ ] Venture thesis defined
- [ ] ICP/customer defined
- [ ] Primary problem/alternative defined
- [ ] Offer/pricing hypothesis defined
- [ ] Unit economics model exists
- [ ] Biggest risk identified

## Brand + domain
- [ ] Name selected
- [ ] Search/conflict review completed
- [ ] Domain availability verified before purchase recommendation
- [ ] Domain ownership verified if purchased
- [ ] Positioning/tagline/tone defined

## Business readiness
- [ ] Legal/regulatory requirements classified
- [ ] Payment readiness classified
- [ ] Privacy/terms/refund needs classified
- [ ] Bookkeeping/invoicing path defined
- [ ] Fulfillment path exists

## Repository + backend
- [ ] GitHub repository exists
- [ ] No secrets committed
- [ ] Environment variables documented
- [ ] Production database exists if required
- [ ] Validation/security/RLS reviewed where applicable
- [ ] Lead/order persistence tested

## Website + UX
- [ ] Mobile-first design verified at 375/390/430px
- [ ] Quiet Luxury / Quiet Power design standard met
- [ ] Hero communicates offer clearly
- [ ] One clear primary CTA
- [ ] Progressive conversion flow works
- [ ] Long exposed forms avoided where possible
- [ ] Carousel/swipe behavior works where used
- [ ] No accidental horizontal overflow
- [ ] Success/error/loading states exist

## Content authority
- [ ] Entity/About content exists
- [ ] Core service/product pages exist
- [ ] How It Works/mechanism exists
- [ ] Real buyer Q&A exists
- [ ] Comparison content exists where strategically useful
- [ ] Case studies include only verified evidence
- [ ] No invented reviews/results/partners/claims

## Search + AI discovery
- [ ] Unique titles/meta descriptions
- [ ] Canonical URLs
- [ ] sitemap.xml
- [ ] robots.txt
- [ ] Internal linking
- [ ] Factual structured data
- [ ] Service/location pages contain unique value
- [ ] llms.txt if useful
- [ ] services.json / agent manifest if useful
- [ ] OpenAPI/MCP files/endpoints if useful
- [ ] Machine-readable assets use production domain

## Analytics + attribution
- [ ] Primary CTA tracked
- [ ] Funnel start tracked
- [ ] Conversion tracked
- [ ] Lead/order ID persisted
- [ ] Source/UTM attribution persisted where possible
- [ ] Qualified/won outcome can be recorded
- [ ] Revenue/payment events tracked if applicable

## Deployment
- [ ] Production build succeeds
- [ ] Vercel/hosting deployment verified
- [ ] Custom domain connected
- [ ] DNS verified
- [ ] HTTPS/SSL verified
- [ ] Canonical www/root behavior verified
- [ ] Production smoke test completed

## Acquisition
- [ ] First GTM channel selected
- [ ] CAC ceiling or economic constraint defined
- [ ] Outreach/PPC/partner execution path exists
- [ ] Kill criteria defined for paid tests

## Final verification
Every item must be classified:

- VERIFIED
- IMPLEMENTED, NOT VERIFIED
- BLOCKED
- NOT APPLICABLE

Do not call the business launched if a critical customer-acquisition, conversion, persistence, payment, or fulfillment path remains unknown.
