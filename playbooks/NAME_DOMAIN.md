# Name + Domain Playbook

## Objective
Select a defensible, memorable business name and production domain using live evidence rather than taste alone.

## Naming research
Research:

- direct and adjacent competitor names
- search-result conflicts
- confusingly similar companies
- pronunciation/spelling risk
- category conventions
- social-handle conflicts when material
- linguistic/international issues when relevant
- trademark risk indicators
- domain availability

## Name scoring
Score finalists:

| Factor | Weight |
|---|---:|
| Brandability | 20% |
| Memorability | 15% |
| Domain quality | 15% |
| Category relevance | 10% |
| Search distinctiveness | 10% |
| Trademark/confusion risk | 10% |
| Pronunciation/spelling | 10% |
| Expansion potential | 10% |

Recommend one winner unless a genuine strategic trade-off requires two.

## Domain workflow

`search → verify availability → inspect history/reputation → inspect search conflicts → inspect backlink/spam risk when relevant → score → recommend → purchase/handoff → connect → verify`

## Domain rules
Prefer:

1. exact brand `.com` when strong and economically rational
2. local ccTLD for geographically focused businesses
3. short, pronounceable, easy-to-type alternatives
4. brandability over keyword stuffing

Avoid:

- unnecessary hyphens/numbers
- misleading extensions
- legacy spam/toxicity
- confusing competitor similarity
- claims of availability without live verification

## Purchase boundary
Purchasing may require billing or account approval. If blocked:

- identify the exact preferred domain
- provide the shortest purchase path
- continue every independent launch task
- never claim ownership until verified

## Post-purchase verification
Confirm:

- registrar ownership/control
- DNS access
- production A/CNAME records or platform nameservers
- canonical host choice
- HTTPS/SSL
- redirect behavior
- no stale conflicting records

## Output

- recommended name
- recommended domain
- scoring rationale
- conflicts/risks
- purchase status: verified / blocked / not purchased
- DNS status
