# Templates

Reusable assets for launching new ventures quickly.

## Available

- `AI_DISCOVERY_TEMPLATE.md` — llms, services, agent manifest, OpenAPI/MCP guidance and agent truth boundaries.
- `UNIT_ECONOMICS_TEMPLATE.md` — contribution margin, CAC ceiling, payback and LTV scenario framework.
- `STARTER_APP_SPEC.md` — reusable production application capabilities, config surface, data, analytics, SEO and deployment requirements.
- `PRODUCTION_LAUNCH_CHECKLIST.md` — final verified zero-to-one launch gate.

## Future implementation assets

The next compounding layer is code-level starter material for common venture types, including:

- mobile-first landing/funnel components
- service/location page generator
- Supabase lead schema
- CRM pipeline mapping
- analytics event map
- outreach tracker

Templates must remain factual, configurable, and safe to reuse across ventures without carrying over private client data, unsupported claims, prices, locations, customer records, or credentials.
